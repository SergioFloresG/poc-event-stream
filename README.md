## Description

This project is a proof of concept (POC) that implements a Server-Sent Events (SSE) server using
Spring WebFlux and Project Reactor. It allows clients to subscribe to a continuous flow of events
generated by the server.

## Features

- Implementation of Server-Sent Events (SSE) with Spring WebFlux
- Fake data generation with DataFaker
- Request rate limiting with Bucket4j (15 requests per minute)
- Reactive processing with Project Reactor

## Endpoints

### POST `/stream-sse`

This endpoint provides a server-sent events (SSE) stream. Clients can send a JSON object that serves
as a template for the data they will receive in the stream.

#### Required Headers:

- `Accept: text/event-stream`
- `Content-Type: application/json`

#### Request Body:

The request body must be a JSON object. This object can contain special values:

- Values starting with `@` will be replaced with dynamic values that vary in each message.
- Values starting with `#` will be replaced with constant values that remain the same for all
  messages.

#### Example 1: Request with simple JSON

##### Request:

```sh
curl -N -X POST \
  -H "Accept: text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"message": "Hello World"}' \
  http://localhost:8080/stream-sse
```
